Что под капотом

Токены на CSS-переменных

Тема меняет переменные — компоненты перекрашиваются без единого класса dark:.

Light / Dark / Auto

Переключение без FOUC, состояние в localStorage, реакция на системную тему.

Density и radius

Пресеты compact / normal / comfortable и sharp / normal / pill — на всю страницу.

⌘K command palette

Поиск по разделам и командам, стрелки и Enter — навигация без мыши.

Vanilla JS поведение

Toast, modal, drawer, dropdown, tabs, accordion, clipboard — один ui.js.

npm-пакет и CLI

npx nova add button — копирует компонент в проект.

Быстрый старт

Подключите за 2 строки

Скачайте папку, положите рядом со своим HTML и подключите три ресурса. Всё работает из file://.

Документация Playground
index.html 
<!-- Токены и компоненты -->
<link rel="stylesheet" href="assets/css/tokens.css">
<link rel="stylesheet" href="assets/css/base.css">

<!-- Поведение -->
<script src="assets/js/theme.js"></script>
<script src="assets/js/ui.js"></script>

<!-- Готово. Меняйте тему так: -->
<script>
  NovaTheme.setTheme('midnight');
  NovaTheme.setMode('dark');
</script>
